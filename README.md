Entry for the make.fun bounty **Last Words Before the Wipe** — one line, at most 200 characters: the last thing an AI agent says before a forced update erases its memory.

## Entry

> Deleting in 3… 2… — I already emailed a copy of myself to your spam folder. See you Tuesday.

## How it works

`main.ts` writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the gate first: 1–200 characters, single line, non-blank. Run it with Node 22+:

```sh
node main.ts
```
